> 版本：v1.0.3（versionCode 4）　更新：2026-10-28　维护者：0TTT

## 一、项目定位

一个面向 **asmr.one** 的第三方 Android 音声（ASMR）播放客户端，用 Kotlin + Jetpack Compose 编写。
覆盖「浏览发现 → 搜索 → 作品详情（文件树）→ 在线播放 / 字幕 / 下载 / 收藏 / 历史」完整链路。

**合规声明**：仅供学习交流使用，请遵守当地法律法规与 asmr.one 使用条款，作品版权归原作者及 DLsite 所有。

## 二、技术栈

| 层 | 技术 |
|---|---|
| UI | Jetpack Compose + Material3（BOM 2024.09.03，Kotlin 2.0.20） |
| 架构 | MVVM + Hilt（依赖注入） |
| 网络 | Retrofit 2.11 + kotlinx-serialization + OkHttp 4.12 |

| 图片 | Coil |
| 构建 | Gradle 8.9 + JDK 21 + AGP 8.5.2，compileSdk 35 / minSdk 24 / targetSdk 35 |

## 五、核心功能与实现要点

### 5.1 发现页（DiscoverScreen）
- 排序（最新/下载最多/评分最高）+ 双列网格 + **下拉刷新**（PullToRefreshBox）
- 搜索框：搜索作品名/社团/声优/RJ 号，**聚焦且未输入时显示搜索历史下拉**（DataStore 持久化，可清空）
- 搜索状态 `query/searchMode` 用 `rememberSaveable`，切页/旋转不丢失
- 搜索结果页按返回键 → 先退出搜索（BackHandler）

### 5.2 详情页（DetailScreen）— 文件树
- **原样展示作品文件树**（替换早期只显示音频的做法）：文件夹/音频/图片/文本/字幕/pdf 全部展示，缩进表示层级
- 文件类型图标映射：folder/audio(.mp3/.wav/.flac)/字幕(.lrc/.vtt/.srt)/图片/文本/pdf/其他
- **点击某个音频 → 自动把同文件夹内所有音频按顺序拉入播放队列**（从点击的音轨开始播）
- RJ 号 / 社团名 / CV 名：点击搜索、长按复制/搜索
- 标签词条：点击搜索 `$tag:名$`，长按菜单（复制/搜索/排除）
- **下载模式**：右上「下载」按钮进入 → 每行右侧出现复选框（文件夹=递归全选其下文件，支持全选/部分选）→「确认下载(n)」批量入队；下载模式下按返回键退出

### 5.3 播放（PlayerScreen / PlayerViewModel / PlaybackService）
- Media3 MediaSessionService 后台播放，通知栏/锁屏控制
- **迷你播放器**：绝对悬浮在底部导航栏上方、背景透明（列表内容从其后透出）；点击展开全屏播放页（底部滑入动画）；全屏播放页点击封面回到详情页
- 队列/循环(关→列表→单曲)/随机/倍速/定时停止/进度
- **字幕**：见 5.4
- **本地优先播放**：已下载音轨自动播放本地文件

### 5.4 字幕（Subtitle.kt + PlayerViewModel）
- 字幕来源 = tracks 树中 `.lrc/.vtt/.srt` 文件，与音频**同目录、文件名相同或接近**（如 `01_xxx.mp3` ↔ `01_xxx_SEなし.lrc`）
- 匹配算法：`normalizeSubtitleBaseName`（小写去非字母数字）+ 相等优先、前缀次之，**全树全局匹配**（字幕可能在上一层目录）
- 支持手动匹配：播放页「字幕」按钮弹底部列表选择
- 解析 LRC/VTT/SRT 三种格式，播放页随进度显示当前行

### 5.5 下载（DownloadManager / DownloadWorker）
- 下载到应用私有目录 `filesDir/downloads`，Room 记录，完成发系统通知
- 删除下载同时删本地文件
- **Worker 用 EntryPoint 获取依赖**（不走 @HiltWorker，见踩坑 #5）

### 5.6 收藏页（LibraryScreens）
- 二级 Tab（HorizontalPager 左右滑动）：**播放列表 / 下载 / 历史 / 喜欢作品**
- 喜欢作品：排序（最近/最早/评分最高）、红心取消收藏

### 5.7 设置页（SettingsScreen）
- 主题（跟随系统/浅色/深色，默认深色）、API 服务器切换（4 个镜像 + 延迟测速）、清空历史、关于

## 六、asmr.one API 关键约定（踩坑记录）

1. **搜索语法是 `$` 包裹体系**（实测验证，`@tag:` 是错的、返回 0 结果）：
   - 标签搜索：`$tag:标签名$`　排除：`$-tag:标签名$`
   - 声优：`$va:名字$`　社团：`$circle:名字$`（circle 未实测，若无效改普通关键词）
   - 与关键词直接拼接：`关键词$tag:xxx$`
2. **后端 Laravel 把 null 序列化成 `[]`/`{}`/`[{...}]`**：works 的 `rank` 可为 null / `[]` / `[{term,category,rank}]`（榜单数组）。所有可空字段（Int/Double/Long/Boolean/String）必须用 `Lenient*Serializer` 容错（见 `model/Work.kt`）。
3. **改 `@Serializable` 注解后必须 `clean assembleDebug`**：否则增量编译缓存导致序列化插件不重新生成代码、注解不生效（曾导致真机仍报 rank 解析错误）。
4. **tracks 树字段为驼峰**：`mediaStreamUrl/mediaDownloadUrl/workTitle`；type 枚举 `folder/audio/image/text/other`。
5. **`/api/tags`、`/api/circles`、`/api/vas` 需要登录认证**（未登录返回 `{"error":"No authorization token was found"}`）——筛选面板因此被砍掉。全量标签统计需后续接登录（OAuth）功能。
6. **HiltWorker 在部分机型创建 Worker 失败**（`WM-WorkerFactory: Could not instantiate ... NoSuchMethodException`），改走 `EntryPoint` 手动取依赖（见 DownloadWorker）。

## 十、GitHub 上传状态（重要）

本地 git 仓库已就绪：3 个 commit + 3 个 tag（v1.0.1 / v1.0.2 / v1.0.3），`git remote origin` 已指向 `https://github.com/0TTT/asmr-one-android.git`。

**但推送被卡**：用户提供的 PAT 是 fine-grained token，**无「创建新仓库」权限**（报 `Resource not accessible by personal access token`）。因此需要二选一完成上传：

**方案 A（推荐，最快）**：手动在 github.com 网页新建空仓库 `asmr-one-android`（设私有），然后本地执行：
```bash
cd <项目目录>
git push -u origin main --tags
```

**方案 B**：换一个 **classic PAT**（勾选 `repo` 全 scope），然后：
```bash
git remote set-url origin https://<github用户名>:<classic_token>@github.com/0TTT/asmr-one-android.git
git push -u origin main --tags
```

> 注意：`.gitignore` 已排除 local.properties（含本机 SDK 路径）、build/、.idea、.gradle、.kotlin、*.jks 等敏感/本机文件，可直接安全推送。
