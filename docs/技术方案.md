# AsmrOne 特供版（Android）技术方案

> 目标：为 <https://asmr.one/> 定制一个**精简/纯净版**安卓 ASMR 播放器，浏览、搜索、在线播放、离线缓存、收藏历史。  
> 原则：**复用现有依赖，不引入新三方库**；技术选型全部落在已写入 `gradle/libs.versions.toml` 的依赖上。

---

## 1. 项目概述

- 平台：Android（`minSdk 24` / `compileSdk & targetSdk 35` / JDK 17 / AGP 8.5.2 / Kotlin 2.0.20）
- 形态：单模块应用（`:app`），Material 3 + Compose 单 Activity 架构
- 后端：asmr.one 公开 API，baseUrl `https://api.asmr.one/api/`
- 定位：只做「看作品 → 播放 → 下载 → 收藏历史」，不做账号/社区/评论

## 4. 架构设计（分层）

```
┌───────────────────────────────────────────────────────────────┐
│  UI 层 (Compose)                                              │
│  MainScreen ── Home / Search / Detail / Library / Player      │
│            └─ ViewModel (StateFlow + collectAsState)          │
└──────────────────────────────┬────────────────────────────────┘
                               │ 只依赖 ViewModel
┌──────────────────────────────▼────────────────────────────────┐
│  Repository 层（单例）                                          │
│  AsmrOneRepository —— 合并 Remote + Local，对外暴露 suspend/Flow│
└──────────────┬──────────────────────────────┬─────────────────┘
               │                              │
┌──────────────▼──────────────┐  ┌────────────▼────────────────┐
│  Remote                     │  │  Local                      │
│  AsmrOneApi (Retrofit)      │  │  Room: Favorite/History/    │
│  + OkHttp 拦截器(UA/Referer)│  │        Download             │
│                             │  │  DataStore: 设置            │
└──────────────┬──────────────┘  └─────────────────────────────┘
               │
┌──────────────▼───────────────────────────────────────────────┐
│  Service 层                                                   │
│  PlaybackService (MediaSessionService + ExoPlayer 单例)        │
│  DownloadWorker (WorkManager 后台下载)                         │
└───────────────────────────────────────────────────────────────┘
```

- **单向数据流**：UI 状态统一放在 ViewModel，`StateFlow` 暴露，`collectAsStateWithLifecycle` 收集。
- **依赖方向**：`UI → Repository → (Remote | Local)`；`Service` 被 Repository/UI 通过 Hilt 注入调用，不反向依赖 UI。
- **共享播放器**：`PlayerProvider` 持 `ExoPlayer` 单例，供 `PlaybackService`（后台会话）与 UI 复用。

## 5. 数据模型设计（与 asmr.one 对齐）

### 5.1 网络模型 `data/model`

- `Work`：作品，字段与 API 严格一致（`@SerialName` 处理下划线命名）。
  - 关键：`rate_average_2dp` 是 **float64**（如 4.75）；`vas` 是对象数组 `[{id,name}]`；`tags[].i18n` 是嵌套 `i18n.zh-cn.name`；封面是**驼峰** `mainCoverUrl`/`samCoverUrl`/`thumbnailCoverUrl`。
  - 派生属性：`rjCode`、`coverUrl`（三级回退）、`rating`、`circleName`、`vaNames`。
- `TrackNode`：音轨/文件递归树，`type=folder|file`，`children` 递归，`media_stream_url`（播放）、`media_download_url`（下载）、`size`（int64）。
- `WorksResponse`：`works[] + pagination`。

### 5.2 本地模型 `data/local`（Room 实体）

- `FavoriteEntity`（workId 主键，冗余 title/circle/va/cover/rating/duration/tags 便于离线展示）
- `PlayHistoryEntity`（自增 id，记录 listenedAt）
- `DownloadEntity`（trackUrl 主键，存 localPath/fileSize）

### 5.3 字段对齐策略（防坑）

- Json 配置 `ignoreUnknownKeys=true` + `coerceInputValues=true`：接口多返字段/类型偶发偏差不崩。
- `@JsonNames` 做双命名兜底：`media_stream_url` ↔ `mediaStreamUrl`（部分镜像返 camelCase）。

## 6. 关键流程

### 6.1 浏览 / 搜索

`GET /works?page&order&sort&subtitle` / `GET /search/{keyword}?page&order&sort&includeTranslationWorks` → 分页加载 → 双列瀑布流（Coil 懒加载封面）。

### 6.2 播放链路

`DetailScreen 选曲 → ViewModel 拉 /tracks/{id} → flattenTracks 展平 → MediaItemFactory 生成播放列表 → ExoPlayer.setMediaItems → PlaybackService(MediaSession) 后台播放`。

- 媒体 URL 统一走 `resolvedStreamUrl`（相对路径补全 host）。
- 后台播放：`MediaSessionService` + 通知栏控制，`setHandleAudioBecomingNoisy(true)`。

### 6.3 下载链路

`DownloadManager.download(work, track) → WorkManager.enqueue(DownloadWorker) → OkHttp 流式写文件 → DownloadDao.insert`。

- 联网约束 `NetworkType.CONNECTED`；失败 `Result.retry()`。
- 文件落 `filesDir/downloads`，文件名 `workId_trackTitle.ext`（ext 由 Content-Type + URL 推断）。

### 6.4 收藏 / 历史

`Repository.toggleFavorite` / `addHistory` → Room insert/delete → `Flow` 驱动 UI 实时刷新。

## 8. 关键实现要点与坑

1. **Json 容错**：`ignoreUnknownKeys`/`coerceInputValues` 必须开（已开）。
2. **媒体 URL 相对路径**：`media_stream_url`/`media_download_url` 若为相对路径，需补 `https://api.asmr.one` 前缀；已提供 `resolvedStreamUrl`/`resolvedDownloadUrl` 统一出口。
3. **请求头**：`User-Agent`/`Referer` 由 OkHttp 拦截器统一注入（已注入 `Referer: https://www.asmr.one/`）。
4. **后台播放通知**：Android 13+ 需申请 `POST_NOTIFICATIONS` 权限；前台服务需 `FOREGROUND_SERVICE_MEDIA_PLAYBACK`。
5. **网络环境**：部分网络下 `api.asmr.one` 被干扰，真机走设备自身网络；本机开发环境可能无法直连（curl 已验证 HTTP:000）。
6. **大文件 size**：`TrackNode.size` 已用 `Long?`，避免 int64 溢出。

## 11. UI 布局设计

### 11.1 整体信息架构（单 Activity + 底部导航）

`MainScreen` 使用 `Scaffold`，底部 `NavigationBar` 固定 5 个 Tab，内容区按选中 Tab 切换，点击作品卡片时以状态切换方式进入详情（不引入独立导航栈）：

| Tab | 页面                | 组件                              | 布局                                                              |
| --- | ----------------- | ------------------------------- | --------------------------------------------------------------- |
| 首页  | `HomeScreen`      | TopAppBar + FilterChip + 双列瀑布流  | 顶部标题「AsmrOne 特供版」→ 排序筛选（最新/下载最多/评分最高）→ `LazyVerticalGrid` 2 列卡片 |
| 搜索  | `SearchScreen`    | TopAppBar + 搜索框 + 双列网格          | 顶部标题 → 搜索框（占位「搜索作品名/社团/声优/RJ号」）→ 2 列结果网格                        |
| 收藏  | `FavoritesScreen` | TopAppBar + `LazyColumn`        | 列表行（封面 + 标题 + 社团·RJ号 + 已收藏心形）                                   |
| 下载  | `DownloadsScreen` | TopAppBar + `LazyColumn`        | 列表行（音轨名 + 作品·大小 + 删除按钮）                                         |
| 历史  | `HistoryScreen`   | TopAppBar + `LazyColumn` + 清空按钮 | 列表行（封面 + 标题 + 社团·RJ号·音轨）                                        |
| 详情  | `DetailScreen`    | TopAppBar + 头图 + 音轨列表           | 见 11.2                                                          |
| 常驻  | `MiniPlayerBar`   | 进度条 + 上一曲/播放暂停/下一曲              | 悬浮于底部导航上方，有播放内容时显示                                              |

### 11.2 详情页结构（自上而下）

1. **TopAppBar**：返回箭头 ← | 作品标题（单行截断） | 收藏心形（空心/实心切换）
2. **作品头图**：左封面 120dp 圆角图，右侧纵排 —— RJ 号（主色）、社团名、`CV: 声优`、★评分、时长、发售日期
3. **标签**：`FlowRow` 流式布局的标签胶囊（`i18n.zh-cn` 优先）
4. **音轨列表头**：左「音轨列表」标题，右「全部播放」主色按钮（播放三角 + 文字）
5. **音轨行**（`TrackRow`）：播放三角 | 音轨名（2 行截断）+ 大小 | 下载按钮；行间 `HorizontalDivider`

### 11.3 迷你播放器（MiniPlayerBar）

- 顶部细进度条（`LinearProgressIndicator`，播放位置/总时长）
- 左：音轨名（1 行）+ `社团名 · 作品名`
- 右：上一曲 | 播放/暂停（28dp 主按钮） | 下一曲
- 点击整体可展开全屏播放器（**当前 `onExpand` 传的是空实现，全屏播放页为待办**）

### 11.4 配色与规范

- 主色：紫色系（Material 3 primary，`#534AB7` 一带），评分星用琥珀色，收藏/删除用红色系
- 卡片圆角 8-12dp，列表行 `HorizontalDivider` 分隔，空态居中灰字提示（「暂无收藏/历史/下载/结果」）
- 遵循中国用户习惯：无股票等红涨绿跌场景，无特殊配色约定
